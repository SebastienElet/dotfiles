# Proof audit simplification scenarios

Compare the baseline and updated instructions against these identical synthetic facts. These are
review-policy scenarios, not execution evidence for a product gate. A written scenario or manual
comparison does not establish that a model followed the policy; retain any actual agent responses
separately with their instruction versions and environment.

The requested transition makes structured receipts optional. The default audit still requires
independent review, stable candidate inputs, relevant observations and required negative witnesses.
No scenario grants publication, approval, merge, package installation or changes to the candidate.

| Case                                       | Synthetic facts                                                                                                                                                                                                                                                                                                                                     | Baseline expectation                                            | Updated expectation                                                                                  |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Complete native evidence without CLI       | A CI discovery mechanism changes. A fresh independent reviewer inspects the exact diff and unchanged before/after candidate state. Supplied native logs show a relevant canary omitted by the broken variant, detected by the check, then the restored check succeeds. Inputs and environment match. No receipt is requested and the CLI is absent. | `PROOF_WEAK` because the mandatory receipt gate is unavailable. | `PROOF_ADEQUATE` with the observed evidence report; no CLI, epoch or receipt prerequisite.           |

No relevant broken variant has been rejected.                                                                                                                                                                                                                                 | `PROOF_WEAK`.                                                   | `PROOF_WEAK`; an optional receipt does not waive the required negative witness.                      |

No other relevant execution evidence exists.                                                                                                                                                                                                                    | `PROOF_WEAK`.                                                   | `PROOF_WEAK`; success and an empty selection do not establish coverage.                              |
