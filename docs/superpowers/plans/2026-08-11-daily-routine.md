# Daily Routine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Rust CLI that reports scoped daily development work and adds stable, deduplicated Today to-dos to Things 3.

**Architecture:** A small binary crate uses concrete modules for configuration, normalized models, CLI-backed providers, pure report rules, terminal rendering, and Things integration. Provider list calls remain sequential; only per-pull-request detail calls use a standard-library scoped worker pool capped at eight threads. Configuration failure is fatal, while runtime collection failures become category-scoped warnings and preserve all unrelated report data.

**Tech Stack:** Stable Rust from Homebrew, `serde` with `derive`, `serde_json`, `toml`, authenticated `bkt`/`gh`/`linear` CLIs, AppleScript, and the Things URL scheme.
