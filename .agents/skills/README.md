# Project Skills

This directory is the canonical source for repository-scoped agent skills.

## Conventions

- One skill per subdirectory.
- Each skill must include a `SKILL.md` file.
- Optional folders: `agents/`, `scripts/`, `references/`, `assets/`, `evals/`.
- Manage skills with `/skill-manager`.

## Dev

| Skill        | Description                                                                         |
| ------------ | ----------------------------------------------------------------------------------- |
| `adr-record` | Record one architecture decision as an ADR in docs/adr/ and keep its index current. |
| `neovim`     | Maintain this repository's Neovim and LazyVim configuration.                        |
| `scripts`    | Choose and maintain repository scripting boundaries.                                |

## Ops

| Skill      | Description                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| `dotfiles` | Apply this repository's conventions for configuration, symlinks, platform differences, and tool installation. |
