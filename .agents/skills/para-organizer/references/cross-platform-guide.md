# Cross-Platform PARA Setup Guide

After setting up PARA on the local file system, offer to help the user mirror the same structure on other platforms. This guide explains how PARA extends across the tools people commonly use.

## The Core Principle

Use the **same PARA structure** — with the exact same spelling, punctuation, and capitalization — across every platform. This reduces the cognitive effort of switching between tools because the organizational system is always the same.

However, two important caveats:

1. **Only create a folder when you have something to put in it.** Don't create empty folders "just in case" — you'll end up with a maze of empty folders that clutter your workspace.
2. **Not every category needs to exist on every platform.** A "Zoom Recordings" resource might only live on your computer. Only extend a category across platforms when you need to.

## Which Platforms Get PARA

There are six main places people store digital information. Four of them are organized using PARA:

### Organized by PARA (categorical)

1. **Computer file system** (the root organized through this skill)
2. **Cloud storage drive** (Google Drive, OneDrive, Dropbox, iCloud Drive)
3. **Digital notetaking app** (Notion, Obsidian, Evernote, Apple Notes)
4. **To-do list app** (Things, Todoist, Asana) — _projects and areas only_, since these are the categories that have tasks associated with them

### Organized chronologically (not PARA)

5. **Calendar app** — appointments and meetings organized by date
6. **Photos app** — organized by date automatically

### Sensitive/encrypted (separate)

7. **Password manager** — for tax documents, credit card details, medical data, passwords

## How to Set Up PARA on Each Platform

### Cloud Storage (Google Drive, OneDrive, Dropbox)

Create the same top-level structure:

```
0 Inbox
1 Projects
2 Areas
3 Resources
4 Archives
```

Cloud storage is ideal for content you'll collaborate on with others. The rule of thumb: if it's content that multiple people need to access, it goes in cloud storage. If it's personal, it stays on your local computer or notetaking app.

### Notetaking App (Notion, Obsidian, Evernote)

Create top-level notebooks, folders, or sections:

```
0 Inbox
1 Projects
2 Areas
3 Resources
4 Archives
```

Notetaking apps are best for text-heavy content — meeting notes, research, ideas, outlines, reference material. They usually have the best search functionality, making it easy to find things later.

**Notion-specific guidance**: Create a top-level page for each PARA category, with sub-pages for each project/area/resource. Or use a single database with a "Category" property (Project, Area, Resource, Archive) and a "Status" property.

**Obsidian-specific guidance**: Create top-level folders in the vault. Use links between notes to connect related items across categories, rather than duplicating.

### To-Do List App (Things, Todoist, Asana)

Only Projects and Areas are relevant here — tasks don't typically belong to Resources or Archives.

```
1 Projects/
  - [Each active project as a separate project/list]
2 Areas/
  - [Each area for "free-floating" tasks not tied to a specific project]
```

Most tasks belong to a project. Occasionally you'll have a standalone task within an area (e.g., "Correct typo on website" stands alone within a "Website" area). These are fine as area-level tasks.

## The Storage Flowchart

When deciding _which platform_ to save something on:

1. **Is it an appointment or meeting?** → Calendar
2. **Is it a task?** → To-do list app
3. **Is it text (a note, idea, excerpt)?** → Notetaking app (best search)
4. **Is it content for collaboration?** → Cloud storage drive
5. **Can't go in any of the above?** (too large, specialized file type) → Computer's file system

## Talking Points for the User

When presenting cross-platform guidance, adapt to the specific tools the user mentions. Ask them:

- "Which notetaking app do you use?" → Tailor the notebook/folder setup
- "Do you use a cloud drive like Google Drive or Dropbox?" → Offer to describe the structure
- "What's your task manager?" → Explain the Projects + Areas setup

Emphasize that they don't need to set up everything at once. Start with the platform they use most (besides their file system, which is already done), and add others over time as needed. This follows the PARA principle of organizing "just in time."
